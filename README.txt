דף נחיתה — דיאנה בים

1. העתיקי את התמונה שלך לתיקייה images.
2. שם הקובץ שהקוד מחפש: imagescoach.jpg.png
3. עדכני ב-index.html:
   - מספר טלפון
   - כתובת אימייל
   - מדיניות פרטיות
   - טקסטים והמלצות אמיתיות בלבד
4. הטופס כרגע כולל בדיקת תקינות בצד הדפדפן, אך אינו שולח בפועל.
   כדי לקבל פניות יש לחבר אותו לשירות כמו Formspree / EmailJS או לשרת משלך.
5. לפתיחה: לחצי פעמיים על index.html.

הקבצים מותאמים למחשב ולנייד, כוללים תפריט מובייל, שאלות נפתחות,
סליידר המלצות, אנימציות עדינות ונגישות בסיסית.
